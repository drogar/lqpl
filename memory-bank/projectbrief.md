# LQPL Project Brief

## Project Overview
LQPL (Linear Quantum Programming Language) is a functional quantum programming language based on the semantics presented in "Towards a Quantum Programming Language" by Peter Selinger.

## Core Requirements
- Provide a functional programming language for quantum computing
- Implement the semantics as defined by Peter Selinger's work
- Maintain a modular architecture with separate compiler, emulator, and front-end components
- Support quantum programming concepts within a functional paradigm

## Project Goals
- Create a usable quantum programming language implementation
- Provide tools for both command-line and GUI-based interaction
- Enable experimentation with quantum algorithms and concepts
- Support educational use of quantum programming concepts

## Project Scope
- Compiler implementation in Haskell
- Emulator for quantum program execution
- GUI front-end for easier interaction with the language
- Documentation and example programs
